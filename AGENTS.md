# Работа над Автобанком

- Начинай изменения в отдельной ветке. Перед исправлением ошибки воспроизведи её на синтетических данных и получи падающий тест по ожидаемой причине. После исправления прогони этот тест и весь набор.
- Для новой возможности зафиксируй наблюдаемый результат и один важный пограничный сценарий. Если меняется расчёт, сверь независимый расчёт для обычной продажи, убытка и выплаты или повторной покупки. Учитывай дату движения денег и долю каждого участника.
- При изменениях хранения проверь старые записи, повторное открытие книги, конфликт сохранений и границы доступа между аккаунтами. Для документов проверь, какие поля видит получатель.
- Перед объединением запусти `npm run check` и `npm run build`. Для изменений денег, хранения, доступа и печатных документов получи независимое ревью диффа. Повтори затронутые проверки после правок по ревью.
- В описании изменения укажи результаты проверок и оставшиеся пробелы. Используй вымышленные сделки. Рабочие книги, фото, договоры и токены храни в соответствующих сервисах.
