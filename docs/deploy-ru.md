# Развёртывание Автобанка в России

Памятка для владельца: как поднять портал на российском хостинге и что нужно решить до публичного запуска.
Локальная версия уже работает без внешних сервисов: `npm ci && npm run dev` → http://127.0.0.1:5173,
код подтверждения входа в dev-режиме всегда `123456` (переменная `SMS_DEV_MODE=1` в `.dev.vars`).

## 1. Где хостить

Приложение собрано под Cloudflare-совместимую среду (D1 — база, R2 — фото). Варианты:

- **Cloudflare Workers + D1 + R2** — работает «из коробки» (`npm run build`, wrangler deploy).
  Минус: данные физически хранятся за рубежом. Для публичного портала с телефонами граждан РФ
  это риск по 152-ФЗ (локализация персональных данных). Подходит только для закрытого пилота
  с письменным согласием участников и оценке юристом.
- **Российский VPS (Timeweb, Selectel, Yandex Cloud и т.п.)** — рекомендуемый путь для публичного запуска.
  Понадобится адаптер хранения: SQLite вместо D1 (база уже SQLite-совместима) и S3-совместимое
  хранилище (Yandex Object Storage, Selectel S3) вместо R2. Это отдельная задача разработки,
  в текущей версии не реализована.

До выбора хостинга портал можно гонять локально и в закрытом пилоте на своей машине.

## 2. Что обязательно сделать до публичного запуска

1. **SMS-шлюз.** Подключить российского провайдера (SMSAero, SMS.ru, МТС Exolve и т.п.)
   в функции `sendCode` (`app/auth.ts`). Убрать `SMS_DEV_MODE` из боевого окружения.
   Секреты хранить в переменных окружения, не в репозитории.
2. **152-ФЗ.** Телефон и имя — персональные данные:
   - уведомление в Роскомнадзор об обработке ПДн;
   - политика обработки ПДн и согласие при регистрации (чекбокс/оферта на странице входа);
   - хранение баз на территории РФ;
   - порядок удаления аккаунта и данных по запросу (в кабинете пока нет кнопки удаления — добавить).
3. **HTTPS.** Cookie сессии получают флаг `Secure` автоматически на https. Без HTTPS не запускать.
4. **Резервные копии.** D1: `wrangler d1 export` по расписанию; при SQLite-варианте — ежедневный
   бэкап файла базы и объектного хранилища фото. Проверять восстановление раз в месяц.
5. **Секреты.** `AVTO_VIN_COD_TOKEN` (поиск по госномеру) — опционален; без него поиск отключён.
6. **Мониторинг.** Логи ошибок сервера и лимиты SMS (защита от скручивания бюджета).

## 3. Порядок выкладки (Cloudflare-вариант, для пилота)

```bash
npm ci
npm run check        # типы + 88 тестов
npm run build
npx wrangler d1 create avtobank
npx wrangler d1 migrations apply avtobank   # drizzle/*.sql по порядку
npx wrangler r2 bucket create avtobank-photos
npx wrangler deploy
```

Привязки D1/R2 задаются в конфигурации wrangler (см. `.openai/hosting.json`: DB и BUCKET).
Миграция `0001_portal_foundation.sql` пересоздаёт таблицу книг учёта под многопользовательский
режим — применять только к пустой базе (живых книг в проекте пока нет).

Локально миграции к dev-базе применяет утилита (dev-сервер на время применения остановить):

```bash
node scripts/apply-local-migrations.mjs
```

## 4. Роли и доступы

- **Владелец** книги: участники, приглашения, запись.
- **Редактор**: ведёт учёт (книга, фото).
- **Наблюдатель**: только чтение.
- Партнёры в сделках — отдельный список внутри книги; аккаунт участника связывается с партнёром
  вручную. Приглашение не создаёт партнёра автоматически.

## 5. Известные ограничения текущей версии

- Аудит изменений общего банка (кто, когда, что менял) — фаза 2, ещё не реализован.
- Нет удаления аккаунта и экспорта всех данных по запросу — добавить до публичного запуска.
- Двухфакторная защита — следующая итерация (TOTP; SMS-2FA ненадёжна из-за перевыпуска SIM).
