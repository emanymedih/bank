# Автобанк — отчёт по фазам 1–3 и ревью

Ветка `feature/portal-foundation`. Коммиты: `1b6913f` (фаза 1) → `ca06455` (фаза 2) → `d19267f` (фаза 3 + правки ревью).

## Что сделано

### Фаза 1 — портал и доступ (`1b6913f`)
- Вход/регистрация по телефону РФ + пароль (scrypt), сброс пароля, список сеансов с отзывом.
- Общие книги: роли владелец/редактор/наблюдатель, приглашения по ссылке (7 дней), несколько книг на аккаунт.
- Онбординг «книга → банк → первая машина по ГРЗ», кабинет.
- Cookie HttpOnly/SameSite=Lax/Secure, CSRF-защита мутаций, маскировка чужих телефонов.

### Фаза 2 — аудит книги (`ca06455`)
- Append-only журнал: кто/когда/что/было→стало по всем сущностям книги.
- Лента книги с фильтрами и бейджем новых событий; вкладка «Правки» в карточке авто.
- Retention 1000 событий на книгу, запись чанками под лимит D1 (100 параметров), отказ аудита не ломает сохранение.
- Без ПДн: только user_id + снимок имени.

### Фаза 3 — рабочие инструменты (`d19267f`)
- Общий таск-трекер по машине (срок, автор, просрочка), ближайшая задача — в «Следующих шагах» и реестре.
- Ссылка на объявление (http/https), кнопка «Объявление» в карточке и реестре.
- Предпросмотр «Что изменится» в продаже (прибыль, касса, доли по партнёрам) и выплате (остаток прибыли, касса).
- Итоги «вложено» по этапам (as-of на сегодня), закреплённые фильтры реестра на книгу.
- Единая лента авто со свёрнутыми «Правками участников».
- Обучение при первом входе: тур из 4 шагов, один раз на пользователя, пропуск кнопкой/Escape.
- Совместимость: ledgerClientVersion 5, точечный 409 только при реальной потере задач/ссылки.
