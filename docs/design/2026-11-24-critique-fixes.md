# Закрытие находок финального critique (31/40 → цель 40)

Дата: 2026-11-24. Ветка `feature/design-iteration-1`, коммит `352a40c`.

## P1 — до релиза (закрыто, проверено в браузере)

1. **Undo был невидим на мобильном.** Строка статуса жила в main-контенте за modal-шторкой. Теперь `statusBlock` рендерится внутри открытого инспектора/шторки (`VehicleInspector`, `DesktopInspector`, `Overlay` получили prop `status`), а в main — только когда карточка закрыта. Проверено: удаление задачи из шторки показывает «Задача удалена · Вернуть» в самой шторке, undo возвращает задачу.
2. **Вкладки кассы были недоступны с клавиатуры.** Добавлен `onKeyDown` (ArrowLeft/ArrowRight/Home/End) с переводом фокуса — как в карточке. Проверено: ArrowRight с «Движение денег» переводит на «Капитал в авто».
3. **Open-redirect в `return_to`.** Новый `lib/safe-return-to.ts`: допускаются только внутренние пути, отклоняются `//host`, `/\host` и внешние схемы. Тесты: `tests/design-iteration2.test.mjs`.

## P2 — денежные и честные edge-кейсы (закрыто)

4. **Гонка устаревшего undo.** `save()` очищает статус в начале любого сохранения; undo-замыкание additionally защищено `undoToken` — после новой правки старое «Вернуть» не откатит чужие/свежие изменения.
5. **Доли вне мержа 409.** В `CarForm`: `baseSharesRef`, `allocationKey`, `initialAllocationRef`, `sharesConflict`. Если распределение взносов/долей пользователь не трогал — чужие доли принимаются автоматически (`resetAllocation`). Если трогал — баннер «Доли и взносы изменил другой участник», кнопка «Обновить доли» и блокировка сохранения с понятной ошибкой. Проверены оба пути в браузере внешним PUT и попыткой сохранения.
6. **Ложный успех копирования.** Кабинет: `await navigator.clipboard.writeText` с catch и честным сообщением «Не удалось скопировать автоматически — выделите ссылку и скопируйте вручную».

## P3 — полировка (закрыто)

- Хоткеи обнаруживаемы: placeholder поиска «Авто, VIN или госномер — /», title кнопки «Новое авто: клавиша n».
- Единая метафора вкладок: касса подчёркнута как карточка (`.cash-tabs`), сегменты оставлены только переключателям режимов.
- Токены: `var(--negative, #b3261e)` и ховеры корзины → `--bad` / `--bad-soft`; мёртвое `.metric-title { color: #e1ecfd }` удалено.
- Детектор: `.stage-card` без скругления (квадратные колонки как у Pipedrive) — finding `border-accent-on-rounded` закрыт.
- Зона времени: задачи считают «сегодня» в `Europe/Moscow` (`todayIn` из `app/format.ts`), как реестр.
- Таргеты: `status-close`, `tour-close` — hit-area 44px через `::after`; `link-button` 44px на мобильном.
- Тур: кнопка «Назад»; вход в reset-режиме оставляет вкладку «Вход» фокусируемой.
- Хоткей `n` открывает новое авто только в разделе «Автомобили».
