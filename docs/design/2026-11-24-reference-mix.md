# Микс референсов: folk / Pipedrive / Close / shadcn — только стиль

Дата: 2026-11-24. Ветка `feature/design-iteration-1`. Основание: сообщение владельца про 4 экрана MVP и ссылки-разборы. Решение владельца: из референсов берём **только визуальный образец** (цвета, стиль текста, окон, ячеек, чекбоксов, верстки); юзабилити, экраны, сценарии и функции остаются нашими. CRM-сценарии (канбан как основной экран, база контактов/компаний, звонки/лиды, drag-and-drop) не внедряются.

## Что сознательно НЕ взято
- Канбан как основной сценарий и drag-and-drop этапов (наш сценарий — реестр + шторка).
- База контактов/компаний, звонки, лиды, email-секвенции (наши сущности — авто, касса, доли, партнёры).
- Инлайн-редактирование ячеек как основной способ правки (у нас правка через форму с превью последствий и защитой конфликта 409 — это важнее для денег).
- Холодная серая палитра shadcn: сохранена наша тёплая бумажная идентичность (`--page #f3f1e9`, `--surface #fffdf7`, зелёный `--brand`); из референсов взята дисциплина нейтралей (один hairline, один muted, акцент только на интерактивном/выбранном).
