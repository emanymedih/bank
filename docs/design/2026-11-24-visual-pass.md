# Визуальный проход по образцу folk / Pipedrive / Close

Дата: 2026-11-24. Ветка: `feature/design-iteration-1`. Коммиты: `76fe45e` (итерация 1), `b9ec458` (итерация 2), `f0c7eaa` (визуальный проход).

## Решение владельца

> «Мы берём логику дизайна, а фичи оставляем нашими… весь юзабилити остаётся нашим, берём только образец оформления и дизайна этих проектов.»

Поэтому референсы использованы **только как визуальный образец**. Никакие CRM-фичи (контакты, компании, звонки, лиды, канбан как основной сценарий, drag-and-drop) не добавляются. Экраны, сценарии, поля и расчёты Автобанка не менялись.

## Что взято из образца и как применено

| Референс | Визуальный приём | Где применено (только CSS) |
|---|---|---|
| folk CRM | лёгкость: плоские таблицы без тяжёлых рамок, прозрачная шапка uppercase с трекингом, hairline-разделители строк, мягкий hover | `.work-registry .deal-table`, `.panel`, `.partner-book .partner` |
| Pipedrive | колонки этапов с цветным акцентом сверху и суммами, спокойные поверхности вместо сплошных заливок | `.stage-card`, `.stage-board` |
| Close | шторка с подчёркнутыми вкладками, единая хронологическая лента с рельсом и точками событий | `.drawer`, `.car-tabs`, `.feed-group`, `.prep-timeline` |
| folk / Close | светлые метрики вместо тёмной плашки: крупное число, приглушённая подпись, тонкий акцент слева | `.analytics-metrics .metric.hero:not(.negative)` |

Сигнал перерасхода (`.negative`, `--bad-soft`) сохранён и не перекрывается светлой темой метрик.

## Что осталось нашим (не менялось)

- Реестр сделок таблицей с фильтрами, сортировкой и поиском; этапы как фильтр-карточки.
- Шторка карточки с вкладками «История / Деньги / Работы и фото / Запчасти / Задачи / Правки».
- Касса, доли, прибыли, выплаты, запчасти, фото, задачи, лента правок, тур, кабинет.
- Все сценарии сохранения, конфликтов 409, undo и подтверждений.

## Токены

Добавлен `--line-soft: #e9eae0` для hairline-разделителей; остальные токены итерации 1 без изменений.

- `npx tsc --noEmit` — чисто; `npm test` — 127/127; `npm run build` — успешно.

- Детектор анти-паттернов: `overused-font` (Inter) устранён удалением legacy-тем; `side-tab` (`.prep-timeline li`) заменён рельсом с точкой.
