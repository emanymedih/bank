# Автобанк

Веб-приложение для учёта автомобилей от покупки до продажи. В одной книге доступны карточки машин, расходы, касса, расчёты с партнёрами, аналитика, фотоистория, запчасти и печатные документы.

- [Реестр продуктовых идей и решения по отбору](docs/product-roadmap.md)
- [Приложение и маршруты API](app/)
- [Миграции базы](drizzle/)

## Локальный запуск

```sh
npm ci
npm run dev
```

В среде без авторизации главная показывает демонстрационные записи. Для постоянного хранения сборке нужны D1 (`DB`), R2 (`BUCKET`) и авторизованный вход, который предоставляет среда размещения. Схема D1 находится в `db/schema.ts`. OCR-ресурсы собираются из зависимостей перед запуском и сборкой.

```sh
npm run build
```

Для поиска автомобиля во внешней базе используется необязательная переменная `AVTO_VIN_COD_TOKEN`. Значение задаётся в секретах среды размещения. Загрузка фото для распознавания номера работает отдельно от этого поиска.

Репозиторий содержит исходный код. Данные книг учёта, фото и заполненные договоры хранятся вне репозитория.
