# Разбор пилота Автобанка

1. Назови один проверяемый результат и версии входных материалов. Открой реестр идей и путь пользователя в коде. Отметь этапы, которые уже есть в приложении, подтверждены тестом или ещё зависят от реальных данных.
2. Опиши неудачу пилота в одном предложении. Найди причины на границе схемы, интерфейса, действий партнёров и внешнего сервиса. Для трёх главных укажи первый видимый сигнал, проверку, способ снизить риск и роль ответственного. Для неоднозначных финансовых правил зафиксируй развилку и последствия каждого решения.
3. Прогони один повторяемый сценарий на вымышленных данных. Для денег проверяй чистую прибыль, расчёт для каждого участника и свободную кассу отдельно. Используй обычную продажу, убыток и повторную покупку с выплатой в разные даты. Для совместной книги добавь два разных аккаунта, одновременную правку и попытку открыть чужую книгу.
4. Разложи выводы на подтверждённые, полученные на тестовых данных и открытые. На каждый существенный вывод приложи точное место в коде, формулу, тест или ответ сервиса. Задавай вопрос только там, где данных или решения владельца действительно не хватает.
5. Запиши следующий шаг с критерием приёмки в пилоте. Если это исправление, сначала воспроизведи тот же сбой, затем повтори проверку после правки.
